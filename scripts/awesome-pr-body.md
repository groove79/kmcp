Adds **K-MCP** — https://github.com/groove79/kmcp — to **E-commerce** and **Finance & Fintech**.

K-MCP is an MIT-licensed TypeScript monorepo of MCP servers for Korean platforms: Naver Smart Store, Coupang, Cafe24, Toss Payments and Popbill (e-tax invoices, KakaoTalk notifications). Write tools go through a safety gate (preview + confirm token, optional KakaoTalk human approval). Install with `npx` (`@appmonster/*` on npm); also listed on the official MCP Registry (`io.github.groove79/*`).
